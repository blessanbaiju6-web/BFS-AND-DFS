File System Representation and Search Using BFS and DFS

Description

This project represents a file system as a graph using an adjacency matrix. It implements Breadth-First Search (BFS) and Depth-First Search (DFS) to traverse the graph and search for a specified file.

Features

- Represents files and directories as graph nodes.
- Uses an adjacency matrix to store connections.
- Implements BFS and DFS algorithms.
- Displays traversal order.
- Shows whether the target file is found.

Technologies Used

- Programming Language: C
- Concept: Graphs
- Data Structure: Adjacency Matrix
- Algorithms: BFS and DFS

How to Run

1. Save the program as "main.c".
2. Compile using "gcc main.c -o main".
3. Run using "./main".
4. Enter the number of nodes, connections, starting node, and target node.

Expected Result

The program displays the BFS and DFS traversal orders and indicates whether the specified target node is found.
